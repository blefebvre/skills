# skills

Agent skills following the [Agent Skills](https://agentskills.io) format. Each skill is a self-contained folder under
`skills/<name>/` with a `SKILL.md`, so an agent can install one from its folder URL, e.g.
"Add this skill to the project: https://github.com/blefebvre/skills/tree/main/skills/ema-slack-me".

| Skill | Description |
| --- | --- |
| [ema-slack-me](skills/ema-slack-me) | Send questions, decisions, and status updates over Slack and wait for replies. Requires `SLACK_CHANNEL`. |
